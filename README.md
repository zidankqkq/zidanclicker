# Autoclicker

A simple autoclicker for Windows with a settings window.

## How to run

Open PowerShell, paste this, and press Enter:

```powershell
curl.exe -s https://raw.githubusercontent.com/zidankqkq/zidanclicker/main/autoclicker.ps1 | iex
```

Once the window opens, you can close PowerShell. To quit, close the Autoclicker window.

This command runs code straight from the internet, so read `autoclicker.ps1` first if you want to check what it does.

## Features

- Set clicks per second, from 1 to 200
- Add random variation to click timing
- Click with the left button, right button, or both
- Choose any key or a side or middle mouse button as the keybind
- Use the keybind as a toggle, or hold it to click
- Optionally click only while holding the mouse button, or pause while holding it
- Add a start delay, click hold time, and scheduled pauses
- Hover over any setting to see what it does

## Requirements

Windows with Windows PowerShell 5.1, which is built in. Developed and tested on Windows 11.
